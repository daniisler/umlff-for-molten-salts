# SuperSalt BLEND campaign -- the 5 published blends, to extend the UF3-vs-SuperSalt
# comparison from 4 pure salts to 9 systems. Same CLEAN-5 properties + same pipeline.
#
#     <model_dir>  <prefix>  <composition>  <T1> <T2> <T3>
#
# The <composition> field is a MOLE-FRACTION BLEND -- a colon triggers blend mode in
# md_moltensaltcalc.py: e.g. "Na:0.57,Mg:0.43" = 0.57 NaCl . 0.43 MgCl2. Fractions are
# normalised, scaled to ATOMS, and Cl charge-balances exactly. NO SPACES inside the field.
# (Temperatures are SuperSalt's two reported points + a midpoint, for a 3-point alpha_V/Cp.)
#
# PREREQUISITE MODELS -- fit these BEFORE running (commands at the bottom):
#   2-body: ONE full-chemistry model `2body_full_zbl` covers every blend, Big included.
#   3-body: per-blend SUBSYSTEM models (the full 12-element 3-body is intractable, ~100 GB).
#           Big has NO 3-body (it is full chemistry) -> Big is 2-body + SuperSalt only.
#
# TIMESTEP: blends with Mg/Ca/Zn are stiff -> run at 0.5 fs (DT_FS=0.5). Only NaKSr is safe
# at 1 fs. mtknpt can still blow up for the stiffest (cf. the MgCl2 3-body crash) -> if a run
# diverges, drop to 0.25 fs or switch the barostat to nptberendsen.
#
#   1 fs batch (NaKSr only -- jobs 1 and 6):
#     JOBS_FILE=scripts/md_jobs_blends.txt bash scripts/run_md_jobs.sh 1 1
#     JOBS_FILE=scripts/md_jobs_blends.txt bash scripts/run_md_jobs.sh 6 6
#   0.5 fs batch (the rest):
#     DT_FS=0.5 JOBS_FILE=scripts/md_jobs_blends.txt bash scripts/run_md_jobs.sh 2 5
#     DT_FS=0.5 JOBS_FILE=scripts/md_jobs_blends.txt bash scripts/run_md_jobs.sh 7 9
#
# SuperSalt reference for each blend: scripts/md_supersalt.py with the SAME composition field,
# e.g.  uv run python scripts/md_supersalt.py "Na:0.58,Ca:0.12,Zn:0.30" --temp 1050 --dt 0.5
#
